# Recon 06: dev site on Cloudflare Pages

Asked 2026-11-17 by the orchestrator (follow-up to recon/05). Answered by the recon agent from Cloudflare docs (page dates in brackets). Untrusted content: none reported.

7. **Custom subdomain in the same zone:** yes. Dashboard > Workers & Pages > project > Custom domains > Set up a domain; the CNAME is added automatically because the zone is on Cloudflare. Do NOT hand-create a CNAME to `<project>.pages.dev` first (can cause 522). CAA records, if any, must allow Cloudflare's CAs. Domain validation is by HTTP, so add Cloudflare Access only AFTER the domain is verified. Free: 500 builds/month, 1 concurrent build, 100 projects, 100 custom domains per project, 20,000 files, 25 MiB per file, unlimited previews. No cost. (High) [Custom domains Nov 11 2026; Limits; Known issues]
8. **Deploy method:** both Git integration and Direct Upload from CI are current. A project created with Git integration cannot be switched to Direct Upload later (and the reverse). CI route: `cloudflare/wrangler-action@v4` running `pages deploy <dir> --project-name=<name>`; secrets `CLOUDFLARE_API_TOKEN` (minimal scope: Account > Cloudflare Pages > Edit) and `CLOUDFLARE_ACCOUNT_ID`; job permissions `contents: read` and `deployments: write`. `cloudflare/pages-action` is deprecated in favor of wrangler-action (medium: from search snippets, repo page not fetched). (High for token scope) [Direct Upload with CI Sep 18 2026; Git integration Oct 15 2026]
9. **Headers:** `_headers` in the build output is honored, with per-path rules; a request matching several rules gets headers from all of them (repeated headers are joined, so do not stack two CSPs; use `! Header-Name` to detach). Limits: 100 rules, 2,000 characters per line (a long CSP must fit one line). `_redirects` honored (2,000 static + 100 dynamic). `staticwebapp.config.json` is not read by Cloudflare (medium: inferred). (High) [Headers Nov 12 2026]
10. **Access login:** a self-hosted Access application on the dev hostname with an Allow policy and one-time PIN by email works; free Zero Trust plan is reported as up to 50 users (medium, verify). Add it after the domain is verified. Built-in preview protection (Settings > General > Enable access policy) covers previews only, not the custom domain. [Preview deployments Oct 12 2026; Known issues]
11. **noindex:** preview deployments get `X-Robots-Tag: noindex` automatically; a custom domain on the production deployment does NOT. Set it in the dev build's `_headers`. Simplest layout: a separate dev Pages project whose production branch is `dev`. (High for previews; medium that custom domains attach to production only.)
12. **Pages vs Workers static assets:** no Pages deprecation found; Workers has more features and Workers Builds; the answers above hold for both. (Medium)

Recon's comparison note: Azure SWA Free has no free password protection; Cloudflare Access (Free, email one-time PIN) gives a login on dev at no cost.
